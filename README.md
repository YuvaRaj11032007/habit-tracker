# HabitPulse — Daily Goals & Streak Tracker

HabitPulse is a sleek, modern habit and daily goal tracking dashboard featuring dark mode, streak tracking, interactive progress charts, and category management.

## 🚀 Live Demo
Access the live application here:
👉 **[https://yuvaraj11032007.github.io/habit-tracker/](https://yuvaraj11032007.github.io/habit-tracker/)**

## 🌟 Features
- **Daily Habits & Streak Tracking**: Track completion, log daily progress, and build streaks.
- **Visual Analytics**: Interactive consistency breakdowns and progress metrics.
- **Category Organization**: Filter and organize habits across categories.
- **Local Storage Persistence**: Automatically saves your habits and history directly in your browser.
- **Responsive Dark Theme**: Modern UI optimized for mobile, tablet, and desktop screens.
