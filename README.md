## 🌟 Features
- **Daily Habits & Streak Tracking**: Track completion, log daily progress, and build streaks.
- **Visual Analytics**: Interactive consistency breakdowns and progress metrics.
- **Category Organization**: Filter and organize habits across categories.
- **Local Storage Persistence**: Automatically saves your habits and history directly on your device.
- **Responsive Dark Theme**: Modern UI optimized for mobile, tablet, and desktop screens.
